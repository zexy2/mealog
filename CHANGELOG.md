# Changelog

Notable changes to Mealog. Full notes are on the [releases page](https://github.com/zexy2/mealog/releases).

## [0.1.0] - 2026-11-25

First public release.

- A photo or free text becomes a canonical food with an honest portion range
- Nutrition comes from a verified food database, not from the model; uncertain results go to user review
- Offline evaluation harness over labelled samples, run in CI with the TypeScript and Python test suites
